# Multidimensional evaluation of ASR-based subtitling in Spanish

> This repository will be made public upon publication. During the review process it is provided to the
> reviewers as supplementary material.

Code, configuration and results accompanying the paper:

> J. L. López-Hernández, I. González-Carrasco, J. L. López-Cuadrado and I. Guzmán-Colomina,
> "A Multidimensional Evaluation Framework for Accessibility-Oriented Automatic Subtitling in ASR Systems,"
> *IEEE Access*, 2026 (under review).

The framework evaluates ASR systems for accessibility-oriented subtitling in Spanish along five dimensions:

| Dimension | Metrics |
|---|---|
| Lexical accuracy | WER, CER, Punc-WER, PC-WER |
| Semantic preservation | BERTScore, SeMaScore (XLM-RoBERTa large, layer 17); SBERT-cos (supplementary) |
| Readability | Fernández-Huerta index of the full text (FH) and of each subtitle (FH-subt) |
| Subtitle constraints (UNE 153010:2012) | at most 2 lines of 37 characters, at most 15 characters per second, display time 1-6 s |
| Computational cost | processing time and real-time factor (RTF = processing time / audio duration) |

## Repository structure

```
scripts/
  rerun_controlled.py                 Controlled ASR runs: Whisper (faster-whisper) and Wav2Vec2 + KenLM.
                                      Writes transcripts (.txt), word timestamps (.words.json) and subtitles
                                      (.srt) with three segmentations: native, rule-based and UNE 153010-based.
  punctuation_restoration_wav2vec.py  Punctuation and true-casing restoration of the Wav2Vec2 output,
                                      keeping the original word timestamps.
  check_whisper.py                    Checkpoint, architecture and number of parameters of each Whisper alias.
  make_figures.py                     Figures 3-5 of the paper from the CSV files.
  make_tables.py                      LaTeX tables of the paper from the CSV files.
src/                                  Modules of the transcription application used by rerun_controlled.py:
  custom_normalizations.py            terminology normalization (ablation variant "norm")
  whisper_prompts.py                  initial prompt (ablation variant "prompt")
  wav2vec_transcriber.py              Wav2Vec2 loader
notebooks/
  evaluation_metrics.ipynb            All metrics and statistics (Friedman, Wilcoxon-Holm, effect sizes,
                                      bootstrap confidence intervals, sensitivity analysis, ablation).
config/
  environment_main_run.json           Hardware, package versions and decoding configuration of the main run.
results/                              Frozen results reported in the paper (see results/README.md).
figures/                              Figures 3-5 (PDF/PNG) and the data plotted in Figures 4-5.
tables/                               LaTeX tables generated by make_tables.py.
```

## Evaluated configurations

| Configuration | Checkpoint (Hugging Face) | Params (M) |
|---|---|---|
| Tiny | `Systran/faster-whisper-tiny` | 39 |
| Base | `Systran/faster-whisper-base` | 74 |
| Small | `Systran/faster-whisper-small` | 244 |
| Medium | `Systran/faster-whisper-medium` | 769 |
| Large-v1 | `Systran/faster-whisper-large-v1` | 1550 |
| Large-v2 | `Systran/faster-whisper-large-v2` | 1550 |
| Large-v3 | `Systran/faster-whisper-large-v3` | 1550 |
| Large-v3-turbo | `mobiuslabsgmbh/faster-whisper-large-v3-turbo` | 809 |
| Wav2Vec2 | `jonatasgrosman/wav2vec2-large-xlsr-53-spanish` + 5-gram KenLM | 317 |

Decoding: CPU, int8, beam size 5, language fixed to Spanish (`es`), temperature fallback 0.0-1.0,
`condition_on_previous_text=True`, word timestamps, fixed CTranslate2 seed (42), 10 s warm-up (not timed).
Main run: Apple Mac mini M4 (10 cores), 16 GB RAM, macOS 27.0.1, Python 3.11, faster-whisper 1.2.1,
CTranslate2 4.9.0. Large-v1 was added afterwards with the same script and configuration
(see `results/logs/run_log.csv`).

Note: in faster-whisper the alias `large` resolves to `large-v3` (`scripts/check_whisper.py` shows it).

## Reproducing the results

### Statistics, tables and figures (no data needed)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-analysis.txt
python scripts/make_tables.py results tables
python scripts/make_figures.py results figures
```

The notebook `notebooks/evaluation_metrics.ipynb` also runs without data: if `data/asr_outputs/` does not
exist, it loads the per-video results of `results/` and recomputes the statistical analysis.
Its outputs are written to `results_rerun/`.

### Full pipeline (requires the videos and the reference transcriptions)

```bash
pip install -r requirements-asr.txt        # ffmpeg must also be available in the PATH

# 1. ASR runs (one file per video in data/videos/, with VIDEO-N in its name)
python scripts/rerun_controlled.py --videos data/videos --out data/asr_outputs --dry-run
python scripts/rerun_controlled.py --videos data/videos --out data/asr_outputs --check-determinism
python scripts/rerun_controlled.py --videos data/videos --out data/asr_outputs

# 2. Punctuation restoration for Wav2Vec2
python scripts/punctuation_restoration_wav2vec.py --out data/asr_outputs

# 3. Metrics and statistics: place the references in data/references/ (TEXTO-REFERENCIA-VIDEO-N.txt)
#    and run notebooks/evaluation_metrics.ipynb (GPU recommended for the semantic metrics).
```

With the same ASR outputs, the notebook reproduces exactly the lexical metrics, readability, RTF,
subtitle metrics, ablation and punctuation-restoration results in `results/`, and the statistics
computed from them. Processing times depend on the hardware.

## Data availability

The 15 videos are institutional and educational content of the Spanish Center for Captioning and Audio
Description (CESyA) and the Spanish Center for Cognitive Accessibility (CEACOG). The videos and the reference
transcriptions are not redistributed in this repository because of the rights of the original content; they
are available from the corresponding author upon reasonable request. All derived results are included in
`results/`.
